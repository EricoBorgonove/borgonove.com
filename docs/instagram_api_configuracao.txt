CONFIGURACAO DA API DO INSTAGRAM PARA SORTEIO DE COMENTARIOS

Atualizado em: 14/02/2026

Objetivo
- Buscar comentarios de uma publicacao do Instagram pelo link e sortear no site.

Pre-requisitos
1. Conta Instagram Profissional (Business ou Creator).
2. Conta Instagram vinculada a uma Pagina do Facebook.
3. Conta Meta for Developers.

Passo a passo
1. Criar app no Meta for Developers
- Acesse: https://developers.facebook.com/apps
- Clique em "Create App" e crie o app para uso com Instagram Graph API.

2. Vincular ativos
- Confirme que:
  - Instagram profissional esta conectado a uma Pagina do Facebook.
  - Essa Pagina esta acessivel pela conta usada no app.

3. Gerar access token
- Gere um user access token com escopos:
  - instagram_basic
  - instagram_manage_comments
  - pages_show_list
  - pages_read_engagement
- Em ambiente real, preferir token de longa duracao e renovacao via backend.

4. Obter IG User ID
- Com token valido, consulte o usuario IG conectado.
- Esse valor sera usado no campo "IG User ID" da ferramenta.

5. Obter media_id da publicacao
- A ferramenta usa o link da publicacao para extrair o shortcode.
- Depois percorre /{ig_user_id}/media para localizar o media_id correspondente.

6. Buscar comentarios
- Com media_id, consultar endpoint de comentarios:
  - /{ig_media_id}/comments
- A ferramenta carrega os comentarios e executa o sorteio com suspense.

Como usar no projeto atual
1. Abrir pagina:
- /utilidades/sorteio-instagram

2. Fazer login local (camada inicial de protecao)
- usuario: admin
- senha: 1234

3. Preencher campos
- Access Token
- IG User ID
- Link da publicacao

4. Acoes
- "Buscar comentarios do link"
- "Iniciar sorteio"

Importante (seguranca)
- Hoje o token esta informado na interface para facilitar testes.
- Producao recomendada:
  1. Mover chamadas da Meta API para backend.
  2. Guardar token no servidor (nunca expor no frontend).
  3. Aplicar controle de acesso real (usuarios, sessao e permissao).
  4. Adicionar logs e limite de requisicoes.

Resumo da conversa - Banco de dados na hospedagem (HostGator cPanel)

Status:
- Tema adiado para futuro, para analise posterior.

Pergunta:
- "Conseguimos colocar um banco de dados na nossa hospedagem?"

Resposta:
- Sim, com cPanel da HostGator e possivel criar banco MySQL/MariaDB.

Contexto tecnico alinhado:
- Em hospedagem cPanel (HostGator), o banco e criado no proprio painel.
- Em hospedagem so de front-end, normalmente precisa banco externo + API.
- Para este projeto React/Vite, o front-end nao deve conectar direto no banco.
- O acesso ao banco deve ser feito por backend/API.

Passo a passo citado (cPanel HostGator):
1. Entrar no cPanel.
2. Abrir "MySQL Databases".
3. Criar o banco (ex.: site_db).
4. Criar usuario e senha em "MySQL Users".
5. Vincular usuario ao banco em "Add User To Database".
6. Marcar "ALL PRIVILEGES".
7. Usar phpMyAdmin para criar/importar tabelas (.sql).

Dados de conexao citados:
- DB_HOST=localhost
- DB_PORT=3306
- DB_NAME=<nome_do_banco>
- DB_USER=<usuario>
- DB_PASSWORD=<senha>

Dados definidos para seu cenario (HostGator/cPanel):
- DB_HOST=localhost
- DB_PORT=3306
- DB_NAME=aruana99_meu_site
- DB_USER=aruana99_user_1234
- DB_PASSWORD=<definir_em_secret_ou_env_local>
- DB_CHARSET=utf8mb4

Observacao importante:
- Em cPanel, usuario do banco normalmente usa prefixo da conta (ex.: aruana99_).

Recomendacao registrada:
- Nao expor credenciais no front-end.
- Guardar credenciais em variaveis de ambiente.
- Criar API para ler/gravar dados.
- Se o plano nao suportar Node em processo continuo, usar API em PHP no proprio cPanel.

Plano sugerido para retomar depois:
1. Confirmar tipo de plano da HostGator (suporte a Node ou PHP apenas).
2. Definir stack da API (Node/Express ou PHP).
3. Criar endpoints iniciais (ex.: contato, utilidades que persistem dados).
4. Configurar .env no servidor.
5. Testar conexao e operacoes CRUD basicas.
